# Part X: Distributed Space-Time Systems

### Introduction

Once computation has explicit geometry and explicit time, it naturally extends beyond a single FPGA.

MatterScript can interoperate with deterministic temporal fabrics in which every computation shares a common notion of identity, time, and location. This complements architectures such as MKSTORM, which provide deterministic time-space addressing and synchronization across distributed systems.
